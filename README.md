# Weekly Flow

Gestor semanal de proyectos y tareas con temporizador Pomodoro integrado.

## Qué hace

- Organiza proyectos en secciones (trabajo / personal)
- Lleva seguimiento de tareas por proyecto
- Temporizador Pomodoro con bloques de trabajo, descansos y almuerzo configurables
- Estadísticas y racha de días activos
- Guarda todo localmente (localStorage) y permite exportar/importar tu progreso como JSON

## Cómo usarla

**Como página web:** abre `src/index.html` directo en cualquier navegador.

**Como app nativa de escritorio (Linux):** cada vez que se sube un cambio, GitHub Actions compila automáticamente una versión instalable. Ve a la pestaña **Actions**, entra al run más reciente en verde, y descarga el artefacto `weekly-flow-linux` (incluye `.AppImage` y `.deb`).
